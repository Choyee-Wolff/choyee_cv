CHOYEE WOLFF PORTFOLIO

A static website prepared for the existing choyee_cv GitHub Pages repository.
Open index.html in a browser to view it locally. No build or installation is needed.

Pages
index.html: professional summary, featured dissertation, projects, experience and skills
about_me.html: biography and education
cv.html: updated CV with a Print / save as PDF button
P.cambridge.html: Cambridge house price prediction dissertation
P.telemarketing.html, P.game.html, P.nhs.html, P.pollution.html, P.alex.html: project case studies

The original project page filenames are preserved so existing links continue to work.
The Cambridge charts were extracted from the saved outputs in the public Dissertation notebook.
The models have not been rerun for this website update.
CV wording is based on the Choyee_Wolff.docx supplied in this chat.

Publishing
The same files can be served directly from the root of the choyee_cv repository.
Review the draft pull request before merging it into the GitHub Pages publishing branch.
The old CV2025.pdf is not referenced by the new website. The updated CV is cv.html.
