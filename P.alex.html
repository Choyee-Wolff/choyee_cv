The question

How can a survey dashboard make patterns in data careers easier to explore?

My approach

Using the survey dataset shared by Alex the Analyst, I created a Power BI dashboard bringing together respondents’ roles, preferred languages, education and satisfaction.

Findings & interpretation

Build a clear overview

The dashboard summarises responses from 630 participants and brings multiple career measures into one view.

Compare career experiences

Views of roles, salaries and satisfaction allow patterns within the sample to be explored.

Make the source explicit

This is a guided dashboard project based on Alex the Analyst’s survey data.

Project visualisations

Scope & limitations

The findings describe the survey sample and should not be treated as representative estimates for the wider data profession.
